Password Manager is a secure desktop application built with Python that allows users to store and manage their website credentials in a local SQLite database. 

FEATURES:
1.Store website credentials securely
2.Save username/email and password
3.Local database using SQLite
4.Easy to use Python interface
5.Fast and lightweight application

TECHNOLOGIES USED:
1.Python
2.Tkinter
3.SQLite


PURPOSE:
This project was created to practice Python GUI development database management with SQLite, and file handling while building a practical real-world application
